# whatsapp-v2 — Native Android SIP Client

A production-grade native Android SIP softphone. Audio and video calling, multi-account
SIP registration, Telecom integration, and conferencing against FreeSWITCH.

## Build policy — CI, not laptops

**This project is not built locally.** All builds run on GitHub Actions runners, which
already provide the JDK and Android SDK. There is intentionally no requirement for a
developer to install Gradle or the Android SDK to contribute.

- Push to `main` or open a PR → the **CI** workflow builds and checks.
- The Gradle wrapper binary is generated by the **Bootstrap Gradle wrapper** workflow
  (run once, manually), because a `.jar` cannot be authored by hand.

To build locally anyway, you need JDK 17 and — from Task 4 onward — the Android SDK.

| minSdk | 26 | `gradle/libs.versions.toml` |
| compileSdk / targetSdk | 35 | `gradle/libs.versions.toml` |

Every version lives in the version catalog. No version literal belongs in a
`build.gradle.kts` — CI fails the build if one appears.

## Configuration (not yet required)

From Task 32, the app is pointed at a FreeSWITCH server via Gradle properties or CI
secrets. Hostnames, credentials, and certificates are **never committed** (ADR-005).
